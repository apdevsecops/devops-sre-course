⭐ Flagship — 16 Week Syllabus

5 live hours every week.

Weeks 1–3 — Foundations + AWS CI/CD

Week 1: Linux, shell, permissions, processes; Git/GitHub; Spring Boot/Maven Employee API + Actuator.

Week 2: AWS IAM/ECR, CodeBuild/CodePipeline, CI/CD build/test automation, Docker fundamentals.

Week 3: Dockerize the Employee API; Pipeline → Docker → ECR → ECS Fargate.

Weeks 4–5 — Docker + ECS

Week 4: ECS services/tasks/Fargate, ALB, health checks, CloudWatch.

Week 5: Security Groups, scaling, rollback, troubleshooting and Project 2 demo.

Weeks 6–7 — Terraform

Week 6: Terraform providers, resources, variables, state, networking and IAM.

Week 7: Terraform ECR/ECS/ALB, modules and Project 3 demo.

Weeks 8–9 — DevSecOps

Week 8: SonarQube, OWASP dependency scanning and quality gates.

Week 9: Trivy container scanning, security gates, remediation and Project 4 demo.

Weeks 10–12 — SRE + Observability

Week 10: SLI/SLO/SLA and error budgets.

Week 11: CloudWatch, Prometheus, Grafana dashboards and alerting.

Week 12: OpenTelemetry, tracing, incidents, on-call, RCA, postmortem and Project 5 demo.

Weeks 13–15 — Kubernetes / EKS + GitOps

Week 13: Kubernetes architecture, Pods, Deployments, Services, ConfigMaps, Secrets and probes.

Week 14: Helm, HPA, EKS and troubleshooting.

Week 15: EKS + ECR, Argo CD/GitOps, rollback and Project 6 demo.

Week 16 — AI-Assisted DevOps/SRE + Final Demo

AI for Linux/Git/Docker/Terraform/Kubernetes, AI-assisted SRE/RCA/runbooks, final integrated portfolio demo and interview readiness.
