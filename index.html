What You Will Build

The Flagship journey is structured around a production-style application and connected infrastructure, delivery, security and reliability projects.

Project 1 — CI/CD Pipeline

Build, test and automate delivery for a Spring Boot application.

GitHub • Maven • AWS CodeBuild • CodePipeline

Project 2 — Container Deployment

Containerize the application and deploy it on Amazon ECS with health checks and rollback.

Docker • ECR • ECS Fargate • ALB • CloudWatch

Project 3 — Infrastructure as Code

Provision and manage cloud infrastructure using reusable Terraform configurations.

Terraform • AWS • IAM • ECR • ECS

Project 4 — Secure Delivery Pipeline

Add code quality, dependency and container security checks to the CI/CD workflow.

SonarQube • OWASP Dependency-Check • Trivy

Project 5 — Observability & SRE

Build dashboards and alerts, work with SLI/SLO concepts and simulate incident analysis.

Prometheus • Grafana • OpenTelemetry • CloudWatch

Project 6 — Kubernetes & GitOps

Deploy the application using Kubernetes, Helm and a GitOps-based delivery workflow.

Kubernetes • EKS • Helm • Argo CD

Project 7 — AI-Assisted DevOps & SRE Operations

Use AI responsibly for log analysis, troubleshooting, RCA assistance, configuration explanation and runbook drafting.

Important: AI-generated outputs are reviewed and validated before applying changes to production environments.

⭐ Flagship — 16 Week Syllabus

5 live hours every week • 80 total live hours • 7 practical projects

Weeks 1–3 — Foundations + AWS CI/CD

Week 1: Linux, shell, permissions, processes; Git/GitHub; Spring Boot/Maven Employee API + Actuator.

Week 2: AWS IAM/ECR, CodeBuild/CodePipeline, CI/CD build/test automation and Docker fundamentals.

Week 3: Dockerize the Employee API; Pipeline → Docker → ECR → ECS Fargate.

Weeks 4–5 — Docker + ECS

Week 4: ECS services/tasks/Fargate, ALB, health checks and CloudWatch.

Week 5: Security Groups, scaling, rollback, troubleshooting and Project 2 demo.

Weeks 6–7 — Terraform

Week 6: Terraform providers, resources, variables, state, networking and IAM.

Week 7: Terraform ECR/ECS/ALB, modules and Project 3 demonstration.

Weeks 8–9 — DevSecOps

Week 8: SonarQube, OWASP dependency scanning and quality gates.

Week 9: Trivy container scanning, security gates, remediation and Project 4 demo.

Weeks 10–12 — SRE + Observability

Week 10: SLI/SLO/SLA and error budgets.

Week 11: CloudWatch, Prometheus, Grafana dashboards and alerting.

Week 12: OpenTelemetry, tracing, incidents, on-call, RCA, postmortems and Project 5 demo.

Weeks 13–15 — Kubernetes / EKS + GitOps

Week 13: Kubernetes architecture, Pods, Deployments, Services, ConfigMaps, Secrets and probes.

Week 14: Helm, HPA, EKS and troubleshooting.

Week 15: EKS + ECR, Argo CD/GitOps, rollback and Project 6 demonstration.

Week 16 — AI-Assisted DevOps/SRE + Final Demonstration

AI for Linux/Git/Docker/Terraform/Kubernetes, AI-assisted SRE/RCA/runbooks, final integrated portfolio demonstration and interview readiness.

Frequently Asked Questions

Is this course suitable for beginners?

The Flagship Program is designed to build from practical foundations. The Crash Program is intended for learners who already have basic Linux, Git and AWS knowledge.

Is the learning focused on theory or practical work?

The program combines concepts with guided labs, project work, troubleshooting and demonstrations.

Does the course include SRE?

Yes. The curriculum covers practical SRE concepts such as SLIs, SLOs, error budgets, observability, alerting, incident response, RCA and postmortem practices.

How is AI covered?

AI is presented as an engineering assistant for troubleshooting, analysis and documentation. Outputs must be reviewed and validated before production use.
